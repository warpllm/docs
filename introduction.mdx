warpllm is a Rust-native AI gateway SDK that gives you a single, unified interface for every major LLM provider. You write one request, and warpllm handles routing it to OpenAI, DeepSeek, Kimi, or OpenRouter — switching providers is as simple as changing the `provider/model` string. The core is compiled Rust, so every Python, Node.js, and Rust application benefits from native-binary performance without a build step on your end.

## Supported providers

warpllm routes requests to four providers today. Each provider is identified by a prefix in the model string:

| Model string | Provider | API key |
| --- | --- | --- |
| `openai/gpt-5-nano` | OpenAI | `OPENAI_API_KEY` |
| `deepseek/deepseek-v4-flash` | DeepSeek | `DEEPSEEK_API_KEY` |
| `kimi/kimi-k3` | Kimi (Moonshot AI) | `MOONSHOT_API_KEY` |
| `openrouter/anthropic/claude-sonnet-4` | OpenRouter | `OPENROUTER_API_KEY` |

The `provider/` prefix is required. warpllm matches the entire string against its built-in registry, so a bare model name like `gpt-5-nano` is rejected rather than silently routed.

## Two product surfaces

warpllm ships as two distinct things you can use independently:

**The SDK** — available as `warpllm` on PyPI, `@warpllm/warpllm` on npm, and `warpllm` on crates.io. Install it in your Python, Node.js, or Rust project and call `chat_completions` directly from your code.

**The HTTP gateway** — an OpenAI-compatible server you can self-host. Point any OpenAI SDK at it and get warpllm's multi-provider routing without changing your application code. The gateway has landed on `main` but is not yet published as a standalone release.

## Current version: 0.3.1

All three packages share the same version number and are released together. Version 0.3.1 adds streaming across every surface — the Rust core, both SDK bindings, and the HTTP gateway — alongside the Kimi provider and the full OpenAI chat-completion roster. It is a breaking release from `0.2.x`: response fields that are optional *and* nullable now distinguish an absent key from an explicit `null`. See the [changelog](https://github.com/warpllm/warpllm/blob/main/CHANGELOG.md) before upgrading.
